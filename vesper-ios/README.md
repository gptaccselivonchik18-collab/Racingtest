# Vesper Gambit для iPhone

Прототип распознавания обычной 2D-доски в другом приложении. Требуется iPhone с
iOS 27. Stockfish 19 Full использует ту же сеть NNUE, что и веб-версия.

1. Выберите полный экран через системное окно захвата.
2. Откройте шахматы со стартовой позицией до первого хода. Подождите пару секунд и вернитесь.
3. На снимке обведите все 64 клетки, укажите цвет фигур снизу и свою сторону.
4. Нажмите «Отслеживать» и вернитесь в шахматы. За белых подсказка рассчитывается
   со стартовой позиции. За чёрных она появляется после подтверждения хода белых.
5. Остановите захват через системное управление либо кнопку «Стоп».

Обработка локальная. Кадры хранятся в памяти во время сеанса. Доска должна
оставаться видимой, неподвижной и контрастной. Прототип сопоставляет кадры с
легальными ходами и при потере позиции приостанавливает подсказки. Системные
баннеры зависят от разрешения на уведомления и настроек iOS. В играх с людьми
пользуйтесь подсказками только там, где это разрешает режим или соперник.

## Сборка

На Mac с Xcode 27 установите XcodeGen, выполните `bash prepare.sh` и
`xcodegen generate`, откройте `VesperCoach.xcodeproj`. Для запуска на iPhone
выберите свою команду подписи в Xcode. GitHub Actions компилирует сборку без
подписи. Она требует подписи перед установкой.

`node Tests/board-tracker.cjs` проверяет алгоритм на синтетических кадрах.
`bash Tests/engine-smoke.sh` запускает нативный движок на Linux. Для проверки
фонового захвата и отображения баннеров нужен физический iPhone.

Stockfish и сеть берутся из зафиксированных исходников Stockfish.js 19.0.1 и
официального хранилища NNUE. Исходники, контрольные суммы и лицензии перечислены
в `prepare.sh`. Chess.js 1.4.0 используется для проверки легальности ходов.
