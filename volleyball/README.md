# Volleyball Simulator / Volley Lab

Первый тренировочный 3D-прототип на **Godot 4.6.3**, GDScript, GL Compatibility.
Самостоятельный проект в этой папке; корневой гоночный проект сохранён.

## Запуск и сборки

Открыть `volleyball/project.godot` в Godot 4.6.3 и нажать F6/F5.
Для получения мобильных сборок устанавливать локальные инструменты не требуется:
GitHub → Actions → **Volleyball mobile builds** → успешный запуск → Artifacts.

- `VolleyballSimulator-Android` содержит `VolleyballSimulator-Android.apk`, arm64, стандартная debug-подпись.
- `VolleyballSimulator-iOS-Unsigned` содержит `VolleyballSimulator-iOS-Unsigned.ipa`, физический iPhone, arm64.
- **IPA НЕ ПОДПИСАН. Перед установкой требуется легитимная подпись средствами sideload. Он не готов к прямой установке.**
- Логи каждого задания доступны отдельными артефактами даже при ошибке.
- На `main` обе проверенные сборки также публикуются в prerelease. APK/IPA загружаются независимо друг от друга.
- Workflow запускается при push в `main`, в PR и вручную (`workflow_dispatch`, после появления workflow в основной ветке).

Версия движка и шаблонов закреплена; установщик проверяет SHA-512 из официального релиза Godot. Xcode берётся с GitHub macOS 15 runner, фактическая версия сохраняется в логе.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Движение | WASD | Левый стик |
| Прицел / сила | Удерживать ПКМ и смещать мышь от точки нажатия | Правый стик |
| Выполнение | Отпустить ПКМ | Отпустить правый стик |
| Верх / низ | 1 / 2 | Сменить технику |
| Угол | Q / E или ползунок | Ползунок |
| Прыжок | Space | Прыжок |
| Спринт | Shift | Удерживать Спринт |
| Повтор упражнения | R | Мяч |
| Меню | Escape | Меню |

Начните с упражнения «Верхняя передача», стоя на стартовой точке. Подготовьте руки,
направьте правый стик вверх экрана и отпустите при сближении мяча с кистями.
«Нижний приём» использует другую высоту контакта. Линия показывает только желаемое
направление, не гарантированную траекторию. Для остальных подач нужно перемещаться.
Кнопка возврата на старт находится в меню. Повтор подачи не телепортирует игрока.

## Физика и архитектура

- `main.gd`: площадка 18 × 9 м, сетка высотой 2.43 м, освещение, камера, линия направления.
- `athlete.gd`: CharacterBody3D, ускорение/торможение, инерция, прыжок, усталость; состояния покоя, подготовки, удара и возврата.
- `ball.gd`: RigidBody3D, масса 270 г, радиус 10.5 см, гравитация, CCD, отскоки, вращение и ограниченная аппроксимация эффекта Магнуса.
- Контакт кисти — сфера, предплечья — капсула. Координаты совпадают с отрисованными суставами. Верхняя передача использует кисти, нижняя — кисти и предплечья.
- В активной части движения проверяется геометрическое пересечение. Вне его импульса нет; один удар может дать только один импульс. Отпускание не читает положение мяча и не ждёт его.
- Импульс учитывает входящую скорость, скорость рук и игрока, направление корпуса, силу, точность, контроль и тайминг.
- Физика 120 Гц; CCD применяется к столкновениям мяча с площадкой/сеткой. Проверка рук дискретная, поэтому экстремально быстрый мяч может проскочить между шагами.
- `training.gd`: шесть фиксированных стартовых положений и скоростей, без наведения на персонажа.
- `hud.gd`: независимые ID пальцев, сброс ввода при потере фокуса, пауза в меню, локальный `user://controls.cfg`.
- Для новых техник можно расширить enum и добавить позу, контактную геометрию и параметры импульса; автомат состояний и интерфейс останутся общими.

## Характеристики 1–100

| Характеристика | Влияние |
|---|---|
| Сила | Скорость активного удара |
| Прыгучесть | Начальная скорость прыжка |
| Скорость | Предельная скорость бега |
| Ловкость | Ускорение и торможение |
| Точность | Угловой разброс |
| Контроль мяча | Разброс силы и сохранение входящей скорости |
| Реакция | Длительность движения рук |
| Координация | Поворот корпуса и угловой разброс |
| Выносливость | Расход энергии при спринте |

Все значения меняются в меню. Seed воспроизводит случайные отклонения при одинаковой
последовательности касаний и физических входных данных; весь физический движок не
обещает побитовую детерминированность между устройствами.

## Проверки

```sh
godot --headless --path volleyball --editor --import
godot --headless --path volleyball --script tests/test_runner.gd
```

Тесты проверяют сцену, пустой удар и промах, верх/низ, геометрический контакт,
защиту от повторного импульса, seed, три пальца и отпускание, отмену ввода,
все шесть подач, реальные отскоки от пола/сетки, контакт через физический интегратор,
прыжок и паузу. CI дополнительно проверяет подпись и manifest APK, структуру IPA,
arm64 Mach-O, платформу iPhoneOS и наличие игрового PCK.

## Будущая подписанная сборка iOS

Текущий pipeline намеренно не использует Apple Secrets. `build_ios.sh` сохраняет
Xcode-проект, и стадия упаковки отделена от экспорта Godot. Чтобы добавить подписанный
вариант, создайте отдельное защищённое задание с GitHub Environment, импортом
сертификата в временную keychain и provisioning profile из Secrets, настоящим
Team ID, `xcodebuild archive` и `-exportArchive` с ExportOptions.plist.
Подходящие имена Secrets: `IOS_CERTIFICATE_P12_BASE64`, `IOS_CERTIFICATE_PASSWORD`,
`IOS_PROVISION_PROFILE_BASE64`, `IOS_TEAM_ID`. Не передавайте их заданиям чужих PR.
Результат называйте `VolleyballSimulator-iOS-Signed.ipa` и проверяйте `codesign`.
Этот будущий путь пока не реализован и не проверен; unsigned pipeline не подделывает подпись.

## Ограничения прототипа

Один игрок, без матча, соперников, счёта и звука. Процедурная анимация упрощена.
Сетка — жёсткий тонкий коллайдер, без деформации. Мяч взаимодействует с активными
руками, площадкой и сеткой; пассивные столкновения с телом не моделируются.
HUD не рассчитан на портретный экран. Тестирование реального multitouch и
производительности на физических телефонах необходимо; сборка в CI его не заменяет.

Документация: [Android export](https://docs.godotengine.org/en/4.6/tutorials/export/exporting_for_android.html),
[iOS export settings](https://docs.godotengine.org/en/4.6/classes/class_editorexportplatformios.html).
