# Звуки VOLLEY / LAB

27 оригинальных коротких эффектов, синтезированных `ci/generate_sounds.py`:
контакты с мячом, поверхности, обувь и движение, интерфейс и свисток.
Записей третьих лиц, речи, фоновой музыки и зацикленных дорожек нет.

Исходники: моно PCM 16 бит / 24 кГц. При импорте Godot использует сжатие
WAV; каждый эффект воспроизводится один раз. Генератор воспроизводим,
для генерации нужны только стандартные модули Python.

Громкость звуков площадки и интерфейса регулируется отдельно. Пространственные
эффекты ограничены 24 одновременно звучащими голосами; тихие шаги не вытесняют
удар по мячу. Пауза в одиночной игре останавливает звуки площадки.
