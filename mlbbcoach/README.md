# MLBB Neural Coach

Нативный iOS-проект в папке mlbbcoach, ветка codex/mlbbcoach репозитория Racingtest. Основная ветка и исходники гонки сохранены.

## Главный приоритет — живой матч

Сквозной прототип захвата, реакции на HP и голоса расширен диагностикой. Полноценный автономный игровой интеллект ещё не реализован. Обязательная проверка настоящего матча на iPhone: [docs/LIVE_MATCH.md](docs/LIVE_MATCH.md). Успешная сборка не доказывает работу в фоне.

## Реализовано

- Тёмный SwiftUI-интерфейс: главная, тренер, ИИ-мозг, память, матчи, знания, модели и настройки в библиотеке.
- SwiftData: память, диалог, оценки ответов, история видеоанализа, стратегические разборы, импортированные знания. iCloud отключён. Ошибка открытия базы показывается пользователю.
- Локальный чат через Apple SystemLanguageModel: проверка доступности Apple Intelligence и русского языка, ограничение контекста, один запрос за раз, отмена, извлечение релевантных заметок и фильтрация знаний по указанному патчу. Облачные модели и платные API не используются.
- Память: создание, редактирование, поиск, отключение и удаление; категории факт с источником, предпочтение, гипотеза и исправление. Источник не делает запись автоматически истинной. Экспорт/восстановление памяти JSON без переустановки.
- Записи матчей: выбор из Файлов, извлечение кадров AVFoundation, Vision OCR с таймкодами и confidence, прогресс, отмена, адаптация к нагреву, сохранение отчёта и экспорт текста.
- HP: ручная калибровка области числа текущее/максимальное; проверка допустимого формата и confidence; GameStateTracker требует два согласованных наблюдения, сбрасывает неизвестные и устаревшие данные. Подсказки низкого HP подавляют повторы. Чужой HP или неверная область могут дать ошибку — автоматического определения своего героя нет.
- Стратегический разбор записи по выборке OCR и персональной памяти. Модель отделяет наблюдения от гипотез; полноценное понимание всех событий матча не заявляется.
- Русская локальная озвучка AVSpeechSynthesizer, паузы, подавление повторов и смешивание с другим аудио. Аудиосессия освобождается после речи.
- JSON-пакеты знаний: патч, дата, HTTPS-источник, лицензия, предварительный просмотр, локальный импорт и загрузка по HTTPS. Схема: docs/KNOWLEDGE_FORMAT.md.
- Core ML: импорт image-классификаторов и Vision-совместимых object-detectors .mlmodel до 150 МБ из Файлов, проверка SHA-256, пробный запуск перед активацией, откат предыдущего файла. Метки модели сохраняются как непроверенные данные, без выдуманной игровой семантики.
- iOS 27: экспериментальный ScreenCaptureKit, системное разрешение, адаптивный интервал 0,5–1 с (от 3 с при нагрузке), CPU Vision / программный Core Image, максимум одна задача Vision; остальные кадры отбрасываются. Добавлены калибровка полосы/числа HP с сохранением, счётчики настоящих фоновых кадров, журнал JSON и задержка от обнаружения до callback начала речи. Калиброванные HP-подсказки предназначены для озвучивания в фоне; физическая проверка ещё необходима. Языковая модель на кадрах не запускается. ScreenCaptureKit отсутствует в SDK симулятора, поэтому этот экран доступен только на поддерживаемом устройстве.
- Главная показывает настоящую категорию нагрева, энергосбережение и физическую RAM устройства. Градусы температуры, FPS игры и расход RAM нейросети не выдумываются.

## Сборка и установка

Откройте PR №1 / Checks или Actions / MLBB Coach unsigned IPA. Сборка выполняется на стандартном runner xcode-27 (Xcode 27.0, iOS SDK 27); тесты — на стабильном macos-15 (ранее macos-26; runner изменён из-за очереди). Workflow также собирает и запускает приложение в симуляторе, проверяет живой процесс и сохраняет screenshot в build-diagnostics. Результаты конкретного запуска смотрите в docs/VALIDATION.md и логе Actions.

Deployment target iOS 26.0; живой захват требует iOS 27.0 и устройства. Исходники Xcode-проекта включены; scripts/generate_project.py детерминированно обновляет проект и Swift Package после добавления Swift-файлов. Локальный Xcode для облачной сборки не требуется.

Workflow автоматически запускается при изменениях кода в PR, после объединения — при push в main; workflow_dispatch доступен после попадания workflow в основную ветку. Фильтр push в main исключает документацию; обновление открытого PR может повторно запускать проверки по общему составу файлов PR.

В успешном запуске скачайте артефакт MLBBNeuralCoach-unsigned, распакуйте ZIP и получите MLBBNeuralCoach-unsigned.ipa и SHA256SUMS.txt. Это неподписанный пакет для внешней подписи. Передайте его в Sideloadly на Windows/macOS и подпишите своей учётной записью Apple. Бесплатная подпись обычно требует обновления каждые 7 дней. Сертификаты, токены и пароли в репозиторий не добавляются.

Установка на реальный iPhone Air, долгий фоновый захват и совместимость background screen-capture с бесплатной подписью ещё не проверены. Если этот режим недоступен после установки, сохраните диагностический отчёт: цель живого тренера остаётся невыполненной.

## Первый анализ записи

1. Сохраните свою запись из Фото в Файлы, откройте Главная / Разобрать запись матча.
2. Выберите видео и при необходимости нужный кадр. Для общего OCR калибровка не нужна.
3. Если игра показывает числовой HP своего героя, включите калибровку и выделите только текущее/максимальное число. Для обычной полосы HP этот распознаватель не подходит.
4. Запустите анализ; после завершения откройте Библиотека / Матчи. В отчёте доступны тактические наблюдения и запрос стратегического разбора локальным ИИ.
5. Если системная модель недоступна или не поддерживает русский, приложение объясняет причину; память, импорт и OCR работают независимо от языковой модели.

## Реальные границы

Обученного детектора MLBB и встроенного обновляемого официального канала патчей пока нет. Герои, миникарта, способности, предметы, позиции и опасные комбинации автоматически не распознаются. Приложение не обещает 15–30 FPS и не вмешивается в клиент игры. Оно не меняет веса нейросети при сохранении заметок. Дообучение Core ML требует подходящей updatable-модели и датасета.

Дальнейшая точность требует легальных записей и разметки по docs/DATASET.md, а производительность и фоновая работа — проверки на настоящем iPhone Air. Правила MLBB о помощниках нужно проверить перед применением во время матча.

Полные требования: docs/REQUIREMENTS.md. Официальные API: docs/FEASIBILITY.md. Проверки: docs/VALIDATION.md.
