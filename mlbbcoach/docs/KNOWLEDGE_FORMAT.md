# Формат пакета знаний

JSON UTF-8, максимум 2 МБ. Обязательные поля:

```json
{
  "schemaVersion": 1,
  "patch": "версия-патча",
  "published": "2026-10-13T00:00:00Z",
  "source": "https://example.com/original-source",
  "license": "лицензия или разрешение владельца данных",
  "entries": ["Это пример формата, а не проверенный игровой факт."]
}
```

До 500 непустых записей, до 4000 символов каждая. Источник должен быть HTTPS. Сначала показывается предварительный просмотр, затем пользователь добавляет данные в локальную базу. Существующие версии сохраняются; совпадающие записи одного патча и источника пропускаются. Дата набора переносится из published.

В Библиотека / Знания можно выбрать файл либо скачать JSON по HTTPS. Приложение не получает доступ к закрытым страницам и не снимает ограничения сайтов. Проверка схемы и лицензии в виде строки не является проверкой достоверности сведений или юридической проверкой разрешения.

В поле текущего патча можно явно указать актуальную версию. Чат извлекает внешние знания для этой версии. Если поле пусто, патч неизвестен и заметки сохраняют свои версии в контексте модели. Встроенного автоматически поддерживаемого канала официальных патчей пока нет: сначала нужен доступный источник с подходящими условиями распространения.
